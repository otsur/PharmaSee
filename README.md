# PHARMASEE APP
An app intended for easy search of medicines in nearby pharmacies


## features

-[] user registration
-[] user login
-[] user logout








## api endpoints

- customer : "/api/v1/customers"
- store : "/api/v1/stores"

### register user 
- "/register"
- through email
- profile picture : "avatar"

### login user
- "/login"
- through username/email

### logout user
- "/logout"

### change current password
- "/change-password"

### get current user
- "/current-user"

### udpate user details
- email and user name: "/update-account"
- avatar: "/update-avatar"






## run

-npm run dev
